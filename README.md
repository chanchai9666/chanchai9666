## About me

I’m a developer focused on practical software: POS systems, backend services, Go utilities, and native macOS apps. I enjoy turning domain problems into reliable, maintainable tools and documenting the architecture along the way.

- Backend APIs and service design
- Go libraries, templates, and reusable helpers

- Native macOS apps with Swift / SwiftUI
